# Automação de testes web: SauceDemo

Testes automatizados com Selenium WebDriver, Python e Pytest,
usando Page Object Model.

## Cenários cobertos
- Login válido, senha inválida e usuário bloqueado
- Adicionar produto ao carrinho

## Como executar
pip install -r requirements.txt
python -m pytest -v

## Tecnologias
Python, Selenium, Pytest
